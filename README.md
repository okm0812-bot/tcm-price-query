# 科學中藥各廠價格查詢系統

輸入藥品名稱，即可比較各藥廠牌價，並支援折扣與 5+1 / 10+1 買贈換算。

## 線上版

- GitHub Pages：<https://okm0812-bot.github.io/tcm-price-query/>
- Repo：<https://github.com/okm0812-bot/tcm-price-query>

**Git repo 是唯一來源**：改動請改 repo 內的 `index.html` 再推上去，Pages 會自動重建。

資料載入採「先顯示、後更新」：開啟頁面時立即顯示內建示範資料（首屏約 0.02 秒就有表格），
同時在背景讀 Google 試算表，讀到就替換成真實牌價。狀態列會標明目前用的是哪一個來源。

## 使用方式

### 查詢

- **首頁不預先列出全部品項**：未輸入關鍵字時只顯示提示列（資料仍在背景載入），
  避免一次渲染數百列造成開啟時卡頓。
- **單筆查詢**：輸入藥名即時比對，命中結果列在表格。
- **多筆查詢**：一次貼上多筆藥名即可，**每行一筆**，或用逗號、頓號、分號分隔，
  逐筆比對後合併成一張表（同一品項只出現一次）。
  提示列會顯示「共 N 筆查詢、命中 M 筆品項｜查無：…」。
- 同一筆輸入的候選清單只針對「最後一段」；用 ↑↓ 選取後按 Enter 套用，
  直接按 Enter 是換行（繼續輸入下一筆）。
- **分類篩選**：下拉可切「複方／單方／錠劑／丸劑」或全部分類，清單本身跟著查詢結果走。
- **各廠牌買贈可個別勾選**：表頭每家廠牌名前有勾選框，只對打勾的廠商套用目前的 5+1／10+1；
  部分廠商沒有搭贈時把它取消即可，控制列另有「全選／全取消」。

### 複製查詢結果

查詢完成後按「**複製查詢結果**」，把畫面上的品項複製到剪貼簿：

- 內容就是目前表格（已套用查詢、分類篩選，以及**當下選的折扣與 5+1／10+1** 換算後的價格）
- 排版為 **LINE 好讀的區塊格式**：每筆品項一行標題，下面每行 2 家廠牌，
  廠牌名稱用全角空格補齊欄寬、價格右靠，**在 LINE 這種非等寬字型下也能對齊**
- 沒有價格的廠牌不列出，貼到 LINE 或記事本不會多出空白欄位
- 多筆品項之間空一行，方便分段閱讀

範例：

```
乙字湯
富田　  480　仙豐　  480
順天堂  480　科達　  540
莊松榮  490　勝昌　  480
```

## 資料來源與載入順序

開啟頁面時**先立即顯示內建示範資料**（不必等網路），接著在背景讀取真實來源：

1. **Google 試算表：4 張工作表分別抓取後合併**（`SHEETS` 常數）
   - `複方(各廠價格)`、`單方(各廠價格)`、`錠劑(各廠價格)`、`丸劑(勝昌)`
   - 用 `gviz/tq?tqx=out:csv&sheet=<工作表名>` 逐張抓；`export?format=csv` 只會給第一張，
     且**帶 `gid` 會回 HTTP 400**，所以不用
   - 每張分頁的資料會標上該分頁當分類（複方／單方／錠劑／丸劑），分類篩選就靠這個
   - 只要求部分分頁成功也能用，狀態列會列出讀到哪幾張
2. **單張匯出 CSV**（第一張分頁）— 4 張都失敗時的備援
3. **本地 `data.csv`** — 把試算表匯出 CSV 後放進同一資料夾
4. **`sample-data.csv`** — 示範資料
5. 全部失敗時仍可用內建示範資料操作，狀態列紅字說明失敗原因

### 表頭格式（四張分頁各不相同，程式都吃得下）

程式**不要求固定欄位順序**，靠表頭文字自動對應：

- 品名欄：`品名規格` / `品名` / `品項` / `品名/規格`，也接受後面帶註記的寫法（如 `品名規格 【複方錠劑】`）
- 規格欄（可省略）：表頭以 `規格` 開頭（如 `規格(丸/包裝)`）→ 會與品名組成完整名稱（`左歸丸` + `1,000丸`）
- 分類欄（可省略）：`分類` / `類別` / `品類`；用分頁分類時，表內自己的細分類會被分頁名稱蓋掉
- 廠牌欄：表頭只要**以廠牌名開頭或包含廠牌名**即可（`富田`、`富田115年11月價格(2026.11.01)`、`勝昌價格` 都行）
- `備註`、`品番` 這類欄位不會被誤認為價格

實際的 Google 試算表是「一廠牌多欄」：同一家可能有 113年、115年9月、115年11月等多個價格欄，
共 34 欄。程式處理方式：

1. 解析每欄表頭的年份／月份（支援民國年 `115年11月`、西元 `2026.11.01`、`2025年12月`、`最新`）
2. 同一廠牌的多欄依新→舊排序；**同一個月同時有「原價」與「新價」時取新價**
3. 取價時**先看最新欄，該欄沒價就往回找有價的欄位**（避免舊欄才有報價的品項變成空白）
4. 頁面下方會列出「各廠牌最新價格欄位」對照，方便核對取的是哪一版

- 表頭若不在第一列（上方有標題列），程式會自動往下找
- **只有所有分頁都沒有某藥廠欄位時**，狀態列才會用紅字列出缺欄
- `丸劑(勝昌)` 分頁只有勝昌價格，所以丸劑品項只有勝昌欄有數字，其餘顯示 `-`
- 錠劑的價格對應的錠數各廠不同（富田與科達 500 錠、勝昌 300 錠、港香蘭 150 克），
  試算表原檔在 `備註` 欄提醒「比價請注意」，網頁沿用同一份資料、不代為換算

## 計算規則

| 模式 | 公式 | 範例（原價 1000） |
| --- | --- | --- |
| 原價 | 原價 × 折扣 | 10 折 → 1000 |
| 5+1 | 原價 × 折扣 × 5/6 | 10 折 → 833 |
| 10+1 | 原價 × 折扣 × 10/11 | 10 折 → 909 |
| 6 折 + 5+1 | 1000 × 0.6 × 5/6 | 500 |

- 先套折扣、再套買贈，最後四捨五入
- 空白 → 顯示 `-`
- 非數字內容（停售、時價…）→ 原樣顯示，不參與運算

## 搜尋比對邏輯

移植自 `tcm-stock` 的 `tcm_lookup-20260825.html`（V2 搜尋核心），同一套評分分層：

| 層級 | 分數 | 說明 |
| --- | --- | --- |
| 完全相同 | 10000 | 正規化後字串相等 |
| 開頭符合 | 9000 + 查詢字數×10 | 品名以查詢字開頭（`桂枝` → `桂枝湯`） |
| 名稱包含 | 8000 + 查詢字數×10 | 查詢字出現在品名中間 |
| 含於品名 | 7600 + 品名字數×10 | 查詢字比品名長，且包含整個品名 |
| 編輯距離 | 5000 + 相似度×1000 | 相似度 ≥ 0.78（僅 3 字以上查詢） |
| 字元集合 | 4000 + 相似度×1000 | 共同字元 ≥ 0.75（僅 3 字以上查詢） |

- **輸入正規化**：簡體轉繁體（含 `锭→錠`）、全形英數轉半形、全形空白、`×＊∗→x`、
  去除 `?？、，,。．.·•` 等殘留標點、移除所有空白。
- **短查詢保護**：2 字以內只允許精確層，不做模糊比對，避免單字亂配。
- **多候選不自動猜**：短查詢命中多筆時全部列出並提示補字，不挑單一答案。
- **多筆輸入**：一次輸入多筆藥名（換行／逗號／頓號／分號分隔），逐筆比對後合併去重列出；
  查無的品項集中列在提示列。
- **輸入即預選**：打字時輸入框下方跳出候選清單（品名＋分類＋符合度，最多 8 筆），
  可用滑鼠點選或鍵盤 ↑↓ 移動、Enter 選取、Esc 收起；選取後只替換「最後一段」查詢，
  前面的品項保留。資料尚未載入完成時，清單會顯示「資料載入中」。
- **低信心提示**：最佳分數未達精確層（< 8000）時標示「查無精確符合，以下為相似品項」。
- **符合度標籤**：每列品名後標示「完全符合／開頭符合／名稱包含／含於品名／相似」等。

### 與原始頁面不同的三處（為配合本頁資料形態）

1. **規格併在品名同欄**：原始頁面的品名與規格（200g／100g）分開儲存。本頁把
   `六味地黃丸 200g` 拆成核心 `六味地黃丸` 與規格 `200g`，兩者都參與評分取高者，
   因此輸入 `六味地黃丸` 也能精確命中。
2. **不因「完全相同」提早 return**：原始資料每個品名只有一筆；本表同一品名可能有多種
   規格（200g／丸劑 500g），提早 return 會把其他規格整列藏掉，故改為精確層全收、靠評分排序。
3. **未移植 `TYPO_MAP` 與 `AMBIGUOUS_TERMS`**：那兩張表是依庫存系統實際品項手工維護
   （例如 `柴胡湯 → 小柴胡湯／大柴胡湯`），本頁品項來自牌價表、清單不同。
   目前錯字與一音多藥是靠評分層與「多筆全列」的行為處理。

## 已驗證項目

以 `node verify.js` 實跑頁面內邏輯，**118 項全數通過**，涵蓋：

- CSV 解析（含引號內逗號、CRLF、BOM、表頭上方有標題列）
- 欄位對應與缺欄偵測、非數字值保留
- **真實試算表表頭**：廠牌名帶年份／月份、同廠多欄取最新、最新欄無價時回退舊欄、無分類欄時自動隱藏
- **多分頁**：錠劑（品名＋規格組成名稱、`規格` 欄不當價格、`備註` 欄不當價格、同月份取新價）、
  丸劑（只有勝昌欄、分類改用分頁名）、合併後分類正確且查得到各分頁品項、缺欄需所有分頁都沒才算缺
- 品名／規格拆分（`桂枝湯 200g`、`六味地黃丸 丸劑 500g`、`科學中藥錠劑 1000錠`、無規格品名）
- 正規化（簡繁、全形數字、空白、標點）與 Levenshtein／字元集合相似度
- 評分分層數值（10000／9030／8020）與符合度標籤
- 搜尋行為：簡體查詢命中、單方與方劑同時列出、同品名多規格都保留、錯一字模糊命中、查無此藥
- **多筆輸入**：換行／逗號／頓號／分號皆可分隔、空白不當分隔（保留「桂枝湯 200g」）、
  合併去重、提示列命中數、查無品項、全部查無的表格訊息
- **空查詢不列全部品項**（只顯示提示列）
- 折扣／5+1／10+1 與疊加計算，各家廠牌買贈可個別勾選
- 表格渲染（千分位、`-` 空白、文字值、符合度標籤）、提示訊息、分類篩選
- 輸入預選清單（候選數量、排序、空查詢不顯示、上限、HTML 轉義）
- **複製查詢結果**：品名標題、廠牌跳過無價者、欄寬對齊、多筆之間空行、數字換算（折扣與 5+1 套用後輸出）

以瀏覽器實測（接真實 Google 試算表 4 張分頁，**1079 筆品項**）：

- 背景載入完成後狀態列顯示「資料來源：Google 試算表（複方／單方／錠劑／丸劑）｜已載入 1079 筆品項」
- 輸入 `乙字湯` → 候選 1 筆、表格列出 11 家價格（富田 480、仙豐 480、順天堂 480…）
- **單方**：`大黃` → 5 筆不同品項（提示列標示未自動挑選）
- **丸劑**：`左歸丸` → 4 筆（複方 910、複方 K 裝 5,460、錠劑 1,300、丸劑 2,200 只有勝昌）
- **錠劑**：`加味逍遙散` → 複方與 2 筆錠劑（500 錠、150 克/瓶）都列出
- 分類篩選切「丸劑」後，非丸劑品項會被濾掉
- 多行輸入 `地黃`、`桂枝汤`（簡體）命中、`六味地黃凡` 以模糊比對命中並提示確認

## 尚未驗證（重要）

- 藥廠牌價的正確性屬業務判斷，程式只負責顯示與換算，未做價格合理性檢查。
- 「取最新欄／往前回退」是依表頭年份判斷，若試算表某欄的年份寫法不固定（例如整欄只寫「最新」而
  無日期），會被當成最新；新增欄位時建議沿用 `115年11月` 或 `2026.11.01` 格式。
- 1～2 字短查詢在 383 筆資料下會頻繁命中多筆並跳出提示，這是刻意設計（不自動挑選）。

# 科學中藥各廠價格查詢系統

輸入藥品名稱，即可比較各藥廠牌價，並支援折扣與 5+1 / 10+1 買贈換算。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 主程式（單檔，含樣式與邏輯，可直接部署） |
| `sample-data.csv` | 示範資料，僅用於驗證畫面與計算，**非實際牌價** |
| `data.csv` | 你自己的實際資料（需自行放入，見下方「資料來源」） |
| `start.bat` | 本機測試用：啟動僅綁定 127.0.0.1 的靜態伺服器並開啟瀏覽器 |
| `verify.js` | 邏輯驗證腳本（`node verify.js`，25 項檢查） |

## 使用方式

### 本機測試（建議）

雙擊 `start.bat`，會開啟 `http://localhost:8123/`。

> 直接用 `file://` 開啟 index.html 時，瀏覽器會基於安全限制阻擋讀取本地 CSV，
> 此時請改用「載入本機 CSV」按鈕手動選檔，或使用 `start.bat`。

### 線上部署（GitHub Pages）

1. 把 `index.html`（可一併放入 `data.csv`）上傳到 GitHub repo
2. repo → Settings → Pages → Source 選 `Deploy from a branch`，分支 `main`、路徑 `/ (root)`
3. 取得 `https://<帳號>.github.io/<repo>/` 連結

> 部署到 Pages 後，資料會優先抓 Google 試算表；若試算表仍未公開，會退回同目錄的 `data.csv`，
> 再退回 `sample-data.csv`，狀態列會標明目前用的是哪一個來源。

## 資料來源與載入順序

程式依序嘗試，成功即停止：

1. **Google 試算表 CSV** — `CSV_URL`（`index.html` 內常數）
   - 試算表權限必須設為「任何人有連結即可檢視」
   - 工作表需為第一張（`gid=0`）
2. **本地 `data.csv`** — 把試算表「檔案 → 下載 → 逗號分隔值(.csv)」後，放進同一資料夾並改名
3. **`sample-data.csv`** — 示範資料，狀態列會以紅字標示「非實際牌價」
4. 三者都失敗時，畫面顯示操作提示，可用「載入本機 CSV」直接選檔

### 表頭格式

```
分類,品名規格,富田,仙豐,順天堂,科達,莊松榮,勝昌,港香蘭,天明,天一,萬國,國科
```

- 「分類」與「品名規格」欄名可用別名（類別/品類；品名/品項）
- 表頭若不在第一列（上方有標題列），程式會自動往下找
- 缺少某藥廠欄位時，狀態列會用紅字列出缺少的欄位名稱

## 計算規則

| 模式 | 公式 | 範例（原價 1000） |
| --- | --- | --- |
| 原價 | 原價 × 折扣 | 10 折 → 1000 |
| 5+1 | 原價 × 折扣 × 5/6 | 10 折 → 833 |
| 10+1 | 原價 × 折扣 × 10/11 | 10 折 → 909 |
| 6 折 + 5+1 | 1000 × 0.6 × 5/6 | 500 |

- 先套折扣、再套買贈，最後四捨五入
- 空白 → 顯示 `-`
- 非數字內容（停售、時價…）→ 原樣顯示，不參與運算

## 已驗證項目

以 `node verify.js` 實跑頁面內邏輯，25 項全數通過，涵蓋：

- CSV 解析（含引號內逗號、CRLF、BOM、表頭上方有標題列）
- 欄位對應與缺欄偵測、非數字值保留
- 折扣／5+1／10+1 與疊加計算
- 表格渲染（千分位、`-` 空白、文字值）、關鍵字搜尋、分類篩選

另以瀏覽器實測（`http://localhost:8123`）：載入備援鏈正常、5+1 與 6 折疊加、
搜尋與還原皆正確，畫面無破版。

## 尚未驗證（重要）

- **Google 試算表的實際內容無法驗證**：本機與雲端環境都連不到 `docs.google.com`
  （連線逾時或 400），因此無法確認該試算表是否已公開、表頭是否與上表一致、資料筆數為何。
  若狀態列出現「試算表缺少欄位」，代表欄名與預期不符，請對照上表修正欄名。
- 藥廠牌價的正確性屬業務判斷，程式只負責顯示與換算，未做價格合理性檢查。
- GitHub Pages 尚未實際部署（需要你的 repo 與授權）。

## 已知限制

- 本機網路環境連不到 `cdnjs.cloudflare.com` 等 CDN，因此本版**不再依賴外部 CDN**
  （原版從 cdnjs 載入 PapaParse，在本機會直接載入失敗），CSV 解析已改為內建實作。
- 13 欄在窄螢幕會出現橫向捲軸，屬預期行為。
